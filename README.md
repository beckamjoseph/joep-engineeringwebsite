# JOEP Engineering & Consultancy Limited Website

## Files
- `index.html` - main website
- `style.css` - design and responsive layout
- `script.js` - mobile navigation and current year

## Run locally
1. Open the project folder in VS Code.
2. Double-click `index.html` or use the VS Code Live Server extension.
3. Test the site in Chrome.
4. Replace/add company images and update the wording with the company's approved content.

## Important before publishing
- Confirm the company name, services, address, phone and email with JOEP.
- Add the company's logo and approved project photographs.
- Replace any placeholder/general service wording with verified company information.
- The contact form currently opens the visitor's email application through `mailto:`. For a professional website, connect it to a form backend or the company's own email server.
- Do not publish claims, certifications, project names or client logos unless the company has approved them.
